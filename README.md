# Alessia Di Giulio — Career Journey Map

An interactive, pin-based map tracing my studies and career path across cities —
built as a portfolio piece for job applications.

**Live site:** enable GitHub Pages in Settings → Pages → Source: `main` / `(root)`,
then visit `https://alessiadigiulio408-ui.github.io/ale-portfolio`

## Files
- `index.html` — page structure
- `style.css` — all visual styling (passport / travel-journal theme)
- `script.js` — map behavior and the "passport page" pop-up
- `data.js` — **edit this to update your story.** Cities, dates, titles, and photo filenames all live here.
- `images/` — add your photos here (see `images/README.md` for exact filenames)

## To update your story
Open `data.js` and edit the text directly — no coding needed beyond editing text
between quotation marks. To add a new city, copy an existing entry in the
`journeyStops` array and fill in its details.
